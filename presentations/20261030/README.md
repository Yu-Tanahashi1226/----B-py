## 発表で伝える3点

1. 検出した投球に、そのときの試合状況を付けて記録できた。
2. 投球直後に同じ表示が続いても、今回の投球後の値に更新済みとは限らない。
3. 前後の表示が不足する場面では、投球結果を決めず、保留する必要がある。
